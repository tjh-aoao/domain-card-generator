# 域·卡牌生成器

一个用于制作、管理和导出《域》卡牌的本地 Web 生成器。

## 功能

- 卡牌编辑与实时预览
- 顶部浅色 / 深色模式切换，自动记住选择；卡牌和打印纸张保持原色
- Word / TXT 批量导入卡牌
- 批量导入图片，按文件名匹配当前分组中的卡牌插画
- 本地牌库保存、克隆、导入和导出
- 单张 PNG 导出
- 批量 PNG 导出
- A4 整页排版导出，方便打印剪裁
- 图片代理接口 `/api/proxy`，用于提升外链图片导出兼容性

## 本地运行

```bash
npm install
npm run dev
```

然后打开 `http://localhost:3000/`。

## 批量配图

1. 在“我的牌库”使用“Word/TXT导入”导入卡牌，或保存编辑器中的卡牌。
2. 选择需要配图的分组（选择“全部”时匹配整个牌库），点击“批量配图”。
3. 多选图片，检查匹配结果后点击“确认导入”。例如 `幻王·奥斯维尔.png` 匹配卡名 `幻王·奥斯维尔`。

匹配时去掉文件扩展名，忽略首尾空格、英文大小写和全角/半角差异，保留名称内部的空格和标点。不使用模糊匹配；卡牌重名、图片重名、没有匹配或不支持的格式会显示原因并跳过。

支持 PNG、JPG/JPEG、WebP、GIF、BMP、AVIF，实际解码能力取决于浏览器。默认替换已有插画（包括默认图），可取消勾选以保留已有图片。导入会重置插画的缩放与位置，其他卡牌内容不变。

图片保留原始质量，卡牌和分组使用浏览器 IndexedDB 保存，不再受 localStorage 的小容量限制。首次打开会自动迁移旧牌库；只有完整写入成功后才清理旧数据。仍可通过 JSON 备份和恢复整个牌库。

批量配图等待数据库保存完成后才显示成功；保存失败时不更改原有卡牌。其他牌库编辑会自动保存，失败时显示重试和备份入口。数据库容量取决于设备剩余空间和浏览器配额；数据仍保存在当前浏览器、当前站点下。

## 生产构建

```bash
npm run build
npm start
```

## 部署

推荐部署到支持 Node.js 服务的平台，例如 Render 或 Railway。这个项目包含 `/api/proxy` 接口，不建议只部署为纯静态网站。

Render 可直接使用仓库中的 `render.yaml`。
